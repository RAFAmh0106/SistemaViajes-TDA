# Sistema de Viajes

Aplicación desarrollada en Java para gestionar información básica de viajes.

## Características

- Implementación de un Tipo de Dato Abstracto (TDA).
- Encapsulamiento mediante atributos privados.
- Constructores y métodos de acceso.
- Cálculo del tiempo y costo de un viaje.
- Método recursivo para calcular el costo total.
- Herencia mediante la clase ViajeEspecial.
- Interfaz gráfica desarrollada con Java Swing.

## Clases

- `tdViajes`: TDA principal.
- `ViajeEspecial`: clase que hereda de `tdViajes`.
- `FrmViajes`: interfaz gráfica de la aplicación.
